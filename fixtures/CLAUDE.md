# fixtures — Agent Context

The cases a Bridge's harness runs, and the inputs and expected outputs they name.
Nothing here executes; `manifest.ttl` declares the cases and the rule each is
judged by, and the crate records where every file came from.

## Every byte is recorded, and inputs are never edited

Every file under `in/`, `facts/`, `expected/` and `findings/` has its digest in the crate,
and `.gitattributes` and `.editorconfig` protect them from normalisation. A
change updates the crate's digest, size and description in the same commit.

An input is one of two kinds, and the crate says which:

- **Copied**: from `../../conformance`, `fixtures/clinical-fhir/` or
  `fixtures/genomics/fhir-genomics-ig/` at the commit the crate's `isBasedOn`
  names, under the same file name, byte for byte, with a `sameAs` to its blob.
- **Authored here**: written for a case the conformance corpus does not hold,
  with the date it was written. An authored input is edited only by replacing
  it, as a new file under a new name.

An input is committed once. A case that needs the same bytes twice names one
file in both of its entries.

An expected graph and a findings file are a Bridge's own `convert --out` and
`convert --findings` output over the input beside it, regenerated by the Bridge
and committed unedited, never written or edited by hand. Both are compared as
graphs, never as bytes: a rerun writes the same triples under other blank node
labels and in another order
([jayostis/cascade-bridge-rs#35](https://github.com/jayostis/cascade-bridge-rs/issues/35)).
A regenerated graph is checked, not trusted: its record names are recomputed
from each rule's inputs by cascade-vocabulary's `tests/naming.py`, and its
version names by the check below.

## Checks CI cannot run

- Each `sameAs` copy is byte-identical to conformance. Compare against the
  **blobs**, never the worktree: a clone with `core.autocrlf=true` holds those
  files as CRLF, and "fixing" that would break the recorded digests.

  ```
  git -C ../../conformance show <commit>:fixtures/<folder>/X.json | cmp - in/X.json
  ```

- Each expected version's `ni:` name is the hash of its own triples and those
  of its nested nodes (`<version>#value`), its own name written as
  `urn:cascade:this-version`, as sorted N-Triples lines
  (cascade-vocabulary's `VersionNamingRule`). From this directory, with
  `pyoxigraph==0.5.11`, the version cascade-vocabulary's `requirements.txt` pins:

  ```
  python3 - expected/*.ttl <<'EOF'
  import base64, hashlib, sys
  import pyoxigraph as ox

  this = ox.NamedNode("urn:cascade:this-version")
  total = good = 0
  for path in sys.argv[1:]:
      triples = [quad.triple for quad in ox.parse(path=path, format=ox.RdfFormat.TURTLE)]
      arrived = {t.object for t in triples if t.predicate.value == "https://ns.cascadeprotocol.org/bridge/v1-draft#arrivedAs"}
      for version in {t.subject for t in triples if t.subject in arrived and t.subject.value.startswith("ni:///sha-256;")}:
          inside = lambda term: isinstance(term, ox.NamedNode) and term.value.split("#")[0] == version.value
          held = lambda term: ox.NamedNode(this.value + term.value[len(version.value):]) if inside(term) else term
          lines = sorted({f"{ox.Triple(held(t.subject), t.predicate, held(t.object))} .\n"
                          for t in triples if inside(t.subject)})
          name = "ni:///sha-256;" + base64.urlsafe_b64encode(hashlib.sha256("".join(lines).encode()).digest()).decode().rstrip("=")
          total += 1
          good += name == version.value
          if name != version.value:
              print("differs:", path, version.value)
  print(f"{good} of {total} version names are the hash of their own triples")
  sys.exit(good != total)
  EOF
  ```
